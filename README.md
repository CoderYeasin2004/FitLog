# Poject Name :- FitLog

# Description :-
 FitLog is a workout tracking website where users can explore exercises, view workout details, and manage their workout plans.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- REST API
- React Toastify

## Key Features

1. Browse and explore different workouts.
2. View detailed workout information.
3. Add workouts to your workout plan.
4. Save workouts for later.
5. Responsive design with custom 404 and loading pages.
